About

A bit about me

I'm a full-stack web developer based in New York who likes turning real problems into simple, thoughtful, genuinely useful web apps.

Most of my work centers on React, Next.js and TypeScript — building data-driven products like a DraftKings lineup optimizer, a real-time catcher-grading dashboard, and analysis tools for the Pokémon TCG. I care about smooth UX, performance, and code the next developer can actually read.

Lately I've been pairing Node, FastAPI and Postgres back ends with AI — a streamed Claude analyst in backstop.ai and a local recommendation model in my DraftKings optimizer — to turn raw data into clear, grounded decisions.

What I'm working on

  • →Grounding AI features in real data so the output stays trustworthy
  • →Integrating public + live APIs to extend what my apps can do
  • →Solving niche and everyday problems alike — from parking to commerce

Outside of code

When I'm not building, I'm playing Pokémon or Magic, teaching chess to elementary-school kids, or lifting at the gym. I'm drawn to things that reward strategy, consistency, and steady long-term improvement — the same instincts I bring to engineering.
